# Tentative roadmap

The major features planned for the versions ahead, tentatively; smaller ones will be included
along the way.

- 0.5: the providers layer rewritten
- 0.6: vision and tool calls
  - 0.6.1: text completion and story mode, a web search tool call
- 0.7: global character registry, adding/removing characters outside stories, inviting
  characters into a story
- 0.8: manually written lorebooks as opposed to automatic lore extraction
  - 0.8.1: lorebooks full import from ST
- 0.9: a director model called before and after each turn, per-character context
