The major features planned for the versions ahead, tentatively; smaller ones will be included
along the way.

|---|---|---|

| 0.3 | character cards import | 2026-08-17 |
| 0.4 | web interface, native Windows support | 2026-09-02 |
| 0.5 | the providers layer rewritten | 2026-09-17 |
| 0.6 | vision and tool calls | 2026-09-26 |
| 0.7 | text completion and story mode, a web search tool call | 2026-10-06 |
| 0.8 | characters library, adding and removing characters outside stories, inviting characters into a story | 2026-10-17 |
