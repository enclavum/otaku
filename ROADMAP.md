# Tentative roadmap

The major features planned for the versions ahead, tentatively; smaller ones will be included
along the way.

- 0.8: global character registry, adding/removing characters outside stories, inviting
  characters into a story
- 0.9: manually written lorebooks as opposed to automatic lore extraction
  - 0.9.1: lorebooks full import from ST
- 0.10: a helper model called before and after each turn, per-character context
