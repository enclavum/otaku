**A roleplay terminal client.** Stories that branch, remember, and grow
their own lore — on your machine, with at-rest encryption you can switch
on.

## Install

```bash
# uv — pulls Python 3.14 automatically, isolated in its own venv
uv tool install otaku

# Homebrew — via the enclavum tap
brew install enclavum/tap/otaku
```
